# Pharmacy Contracts Angular

Angular frontend scaffold for the Pharmacy Contracts Management System API.

## Run

```bash
npm install
npm start
```

The API base URL is configured in `src/environments/environment.ts`.

## Included

- Login with JWT storage.
- SuperAdmin user creation and account activation controls.
- Pharmacy company contract CRUD surface.
- Typed Angular services and models for the API reference.
- Separate component `.ts`, `.html`, and `.scss` files.
